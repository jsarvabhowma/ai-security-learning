# AI Security Learning Paths

A personal study workspace for an AI agents foundation course followed by
three practical AI security certifications, supported by shared notes and labs.

## Learning sequence

| Order | Learning step | Why | Status |
| --- | --- | --- | --- |
| 1 | [Hugging Face Agents Course](learning-paths/hugging-face-agents/README.md) (Units 1–2) | Build a foundation in agent concepts and frameworks before studying their security. | Preparatory |
| 2 | [CAISP](learning-paths/CAISP/README.md) | Learn practical AI and LLM security. | Paid by employer |
| 3 | [CAASE](learning-paths/CAASE/README.md) | Build on that with agent-specific attacks and defenses. | Paid by employer |
| 4 | [HTB COAE](learning-paths/COAE/README.md) | Optional next step for deeper offensive AI; its practical exam lasts seven days. | Optional |

The Hugging Face course is preparation, not a required certification. The
[roadmap](roadmap.md) describes the sequence and what to confirm before
scheduling each exam.

All learning paths live in `learning-paths/`, including the preparatory Hugging
Face course. Each path has its own folder and module notes, linked above.
Use the shared journal for dated reflections across paths.
