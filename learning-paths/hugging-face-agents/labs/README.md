# Hugging Face Agents Course labs

Runnable code from this path's exercises. Put each lab in its own folder named
after its module, for example:

```text
labs/
└── 01-topic-name/
    ├── README.md        # goal, setup, how to run, findings
    ├── requirements.txt
    └── main.py
```

Link each lab from its module note in [modules](../modules/). Keep credentials,
virtual environments and model weights out of Git; see the root `.gitignore`.
Only attack systems you own or are explicitly authorized to test.
